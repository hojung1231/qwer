# 따라 부르기 판정 설정 탐색

`dist/singalong.html`의 판정 상수(YIN 문턱, 중앙값 창, 지연, 판정 폭, 음표 경계 여유)를 정한 스크립트입니다.

입력(이 폴더에 둠, 저장소에는 넣지 않음): 곡마다 `<이름>.f32`(분리한 보컬, 48 kHz 모노 float32)와
`<이름>.notes.json`(`[[시작초, 길이초, MIDI음], ...]`, 음원 시간 기준). 스크립트 안의 곡 이름 목록을 맞춰 고칩니다.

1. `node track.js` — 페이지와 같은 YIN 검출기로 초당 30프레임의 음높이 열을 만듭니다.
2. `python3 opt.py` — 설정 3,240가지를 채점하고, 한 곡을 빼고 고른 설정을 그 곡으로 검증합니다.

채점: 실제 육성을 "맞게 부른 예"로, 같은 육성을 목표음에서 ±1반음·±2반음 어긋나게, 또 20초 밀어 판정한 것을
"틀리게 부른 예"로 씁니다. 목적 함수는 (맞게 부른 예의 일치율) − (반음 틀린 예의 일치율) + 0.3×(검출 비율).

결과(세 곡 평균): 일치율 77% 유지, 반음 틀린 예를 맞다고 본 비율 28% → 16%. 빼놓은 곡에서도 같은 방향이었습니다.
