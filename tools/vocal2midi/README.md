# vocal2midi — 노래(mp3)에서 보컬 멜로디를 MIDI로 추출

가수의 바이브레이션·꾸밈음·박자 밀림을 걸러내고 악보에 가까운 음표를 얻기 위한 파이프라인입니다.

## 실행

```bash
pip install librosa soundfile mido torchcrepe demucs   # ffmpeg 필요
python3 vocal2midi.py 노래.mp3 -o out --bpm-hint 70 --key E --reference reference_score.txt
```

`--bpm-hint`, `--key`, `--reference`는 선택입니다(없으면 템포·조성을 추정하고 평가는 생략).

출력(`out/`)

| 파일 | 내용 |
|---|---|
| `melody_quantised.mid` | 16분음표 격자에 맞춘 멜로디(실제 소리 나는 옥타브) |
| `melody_quantised_score_octave.mid` | 같은 내용을 악보 표기 옥타브로 옮긴 것(`--reference` 사용 시) |
| `melody_raw.mid` | 양자화 전, 가수 타이밍 그대로의 음표 |
| `comparison.txt` | 악보와 추출 결과를 마디별·16분음표별로 나란히 놓고 틀린 칸 표시 |
| `report.json` | 튜닝, 조성, 템포, 평가 수치 |
| `vocal.wav`, `f0.npz` | 분리된 보컬, 프레임별 음고(재실행 시 `--cache`로 재사용) |

## 방법

1. **보컬 분리** (`isolate.py`) — Demucs 가중치를 받을 수 있으면 신경망 분리, 아니면 모델 없이
   스테레오 가운데 성분(L·R이 위상·크기가 같은 주파수 칸)만 남기고 타악 성분과 저역을 제거.
2. **음고 추적** (`pitch.py`) — CREPE(full), 10 ms 간격. 주기성(신뢰도)과 음량도 함께 저장.
3. **유성 판정** — 주기성 히스테리시스 + 최근 8초의 보컬 음량 대비 상대 문턱.
   분리 후 새어 나온 반주(음정은 있지만 10 dB쯤 작음)를 쉼표로 처리하기 위함.
4. **바이브레이션 평탄화** — 약 한 주기(170 ms) 길이의 중앙값 필터로 떨림의 중심음을 취함.
5. **음표 디코딩** (`notes.py`, HMM/Viterbi) — 상태 = 반음 + 무음. 방출 허용폭을 넓게(σ≈0.55반음),
   음 전환 비용을 크게 두어 지속되는 변화만 새 음표가 됨. 조성 밖의 음에는 추가 비용을 두어
   플랫하게 부른 음(예: 낮게 잡은 G#)이 반음 아래(G)로 떨어지지 않게 함.
6. **꾸밈음 흡수** — 110 ms 이하의 스쿱·폴은 인접한 긴 음에 합침.
7. **박자 격자** — 비트 추적 결과에 직선(일정 템포)을 맞춰 16분음표 격자를 만들고,
   가수가 박자보다 앞서거나 밀리는 평균 지연을 ±반 칸 범위에서 찾아 보정.
8. **양자화** — 칸마다 다수결로 음을 정하고, 프레이즈 안의 8분음표 이하 끊김은 앞 음 길이로 돌려줌.
   같은 음이 이어질 때는 보컬 온셋에서 음표를 나눔.

## 평가 (`score.py`)

`reference_score.txt`는 악보 이미지의 1절(7~24마디)을 손으로 옮긴 것입니다. 추출 결과 위로 악보를
밀어 가며 가장 잘 맞는 위치·옥타브를 찾고, 16분음표 칸 단위 일치율과 음표 단위 F1을 냅니다.
`?`가 붙은 마디(11~14)는 악보에 1·2절 성부가 겹쳐 인쇄돼 판독이 불확실해 별도 수치로 분리합니다.

### 「청혼」 결과 (가운데 성분 분리, CPU)

| 지표 | 값 |
|---|---|
| 음고 일치(칸 단위, 전체 18마디) | 52% |
| 음고 일치(판독이 확실한 14마디) | 58% |
| 같은 기준, 앞뒤 16분음표 1칸 허용 | 73% |
| 음표 단위 F1(시작 위치 ±1칸, 음고 일치) | 0.54 |
| 추정 템포 / 조성 | 71.0 BPM / E장조 |

남은 오차의 원인(분석 결과)

- 가수가 악보보다 음을 일찍 끊거나 길게 끄는 구간, 박자를 밀고 당기는 구간.
- "You don't have to cry", "I will make you smile"처럼 다른 멤버가 겹쳐 부르는 구절:
  악보는 한 줄에 적지만 가운데 성분에는 리드 보컬의 지속음만 남아 추출되지 않음.
- 쉼표 구간에 새어 나온 피아노 음.
- 높은 G#을 30~70센트 낮게 부르는 등 음정 자체의 편차(조성 사전확률로 일부만 보정).

Demucs 분리는 이 환경에서 가중치를 받을 수 없어 검증하지 못했습니다.
