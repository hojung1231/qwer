# 이븐 스테이크

두께 3cm 소고기를 원하는 굽기에 맞춰 뒤집어 가며 고르게 굽는 브라우저 게임입니다. 화면 연출이 아니라 열전달 계산 결과로 고기가 익습니다.

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 정적 서버로 엽니다.

```
cd steak && python3 -m http.server 8000
# http://localhost:8000
```

물리 테스트는 저장소 루트에서 `npm test` 로 함께 실행됩니다 (`tests/steak.test.mjs`).

## 조작

고기는 도마, 팬, 오븐 사이를 몇 번이든 오갈 수 있습니다. 팬에서만 굽기, 굽고 도마에서 쉬었다가 다시 시어링하기, 오븐에서 천천히 데운 뒤 센 팬에 짧게 굽는 리버스 시어링 모두 가능합니다. 다 됐다고 판단하면 팬 밖(도마나 오븐)에 있는 상태에서 잘라 채점합니다. 자르는 순간의 상태로 채점하므로 잔열이 퍼질 때까지 기다릴지는 직접 정합니다.

| 동작 | 버튼 | 키 |
| --- | --- | --- |
| 불 세기 0~10 | 불 세기 슬라이더 | ← → |
| 오븐 온도 60~250°C (항상 예열된 상태) | 오븐 슬라이더 | |
| 고기를 도마 / 팬 / 오븐으로 | 고기 위치 | R / P / O |
| 뒤집기 | 뒤집기 | Space |
| 버터 베이스팅 (팬 위에서 누르고 있는 동안) | 버터 베이스팅 | B |
| 자르고 채점 (팬 밖에서만) | 자르고 채점 | C |
| 시간 배속 1·4·16·32·64× | 시간 배속 | 1~5 |

## 물리 모델 (`physics.js`)

- **고기**: 폭 100mm × 두께 30mm 단면을 50 × 30 셀(2mm × 1mm)의 2차원 유한체적 격자로 계산합니다. 셀마다 온도, 수분, 최고 도달 온도, 갈변 지수를 갖습니다.
- **열물성**: 수분량에 따라 열전도도(0.12~0.48 W/m·K)와 체적 열용량이 바뀝니다. 마른 크러스트는 열을 덜 전달하고 더 빨리 뜨거워집니다.
- **팬 접촉**: 기름이 있으면 접촉 열전달계수 520, 없으면 330 W/m²·K. 표면이 마를수록 접촉이 약해집니다.
- **팬**: 하나의 열용량 덩어리입니다. 버너 입력(최대 900W), 대류와 복사 손실, 고기로 빠져나가는 열, 팬에 떨어진 육즙의 증발을 계산합니다. 무쇠(3.0kg), 3중 스테인리스(1.5kg), 코팅 알루미늄(0.9kg)은 열용량과 방사율이 다릅니다.
- **증발과 크러스트**: 100°C를 넘는 에너지는 셀의 물을 끓여 날립니다. 그래서 젖은 고기는 100°C에 묶이고, 마른 층만 그 이상 올라가며 크러스트가 안쪽으로 자랍니다. 공기에 닿은 면은 포화수증기압 차이로 증발 냉각됩니다.
- **육즙 손실**: 최고 도달 온도에 따라 단백질이 수축해 보유 가능한 수분이 줄고, 넘치는 수분이 빠져나갑니다.
- **마이야르 갈변**: 아레니우스식 반응 속도(150°C에서 약 60초에 노릇한 갈색)로 누적되며, 지수가 5를 넘으면 탄 것으로 봅니다.
- **뒤집기**: 격자를 위아래로 뒤집습니다. 자주 뒤집을수록 양면이 번갈아 식으며 더 고르게 익습니다.
- **오븐**: 모든 면이 오븐 공기(대류 + 벽 복사, 약 20 W/m²·K)와 열을 주고받고 표면 수분이 증발합니다. 120°C 오븐에서 3cm 고기 중심을 46°C까지 올리는 데 약 45~50분이 걸립니다. 겉이 미리 말라 있어 시어링 때 크러스트가 빨리 생기고 회색 띠가 얇아집니다.
- **도마**: 아랫면은 도마로, 나머지 면은 공기로 열이 빠지며, 그동안 안쪽에서는 잔열이 중심으로 퍼집니다.

## 채점 (100점)

| 항목 | 배점 | 기준 |
| --- | --- | --- |
| 목표 굽기 | 40 | 레스팅 후 가장 덜 익은 층의 온도가 목표 ±1.5°C 이내면 만점 |
| 회색 띠 | 15 | 목표 +5°C 를 넘게 익은 층 두께 8mm 이하 만점 |
| 위아래 대칭 | 10 | 같은 깊이의 위아래 최고 온도 차 평균 |
| 크러스트 면 A / B | 각 10 | 갈변 지수 1.2~3.8 만점, 창백하거나 타면 감점 |
| 육즙 | 15 | 중량 손실 12% 이하 만점 |
