# 보고또보고

## Android 설치 앱

주요 개발 대상은 `native/`의 React Native·Expo Android 앱입니다. [Android 미리보기 릴리스](https://github.com/hojung1231/qwer/releases/tag/android-preview)에서 APK를 내려받습니다. 자세한 실행 및 사내 Qwen 연결 방법은 [네이티브 앱 안내](native/README.md)를 참고하세요. 아래 내용은 이전 웹 프로토타입에 대한 안내입니다.

휴대폰용 외근 기록 및 보고서 PWA. 사진·영상 촬영, 음성 메모, 기록 선택, 보고서 편집과 공유를 지원합니다.

## 실행

Node.js 22 이상에서 `npm start` 실행 후 http://localhost:4173 에 접속합니다. 추가 패키지는 없습니다. `npm test`로 핵심 로직 및 서버 검사를 실행합니다.

휴대폰에서는 HTTPS로 배포한 주소를 Chrome/Safari로 열고 브라우저 메뉴에서 홈 화면에 추가합니다. PC의 localhost 주소는 휴대폰에서 접속할 수 없습니다. GitHub Pages에는 `dist` 폴더만 정적으로 배포합니다. 카메라·마이크에는 브라우저 권한이 필요합니다.

## 사용

1. 새 작업을 시작하고 제목을 정합니다.
2. 카메라를 켜서 짧게 터치해 사진, 길게 눌러 영상 촬영합니다. 영상에는 마이크 권한이 필요합니다. 가져오기로 기존 사진/영상도 추가합니다.
3. 위 기록을 터치하거나 길게 누르고 움직여 선택합니다. 선택한 기록에 음성 또는 텍스트 메모를 추가합니다. 다시 촬영은 ‘이어서 촬영’으로 새 기록을 만듭니다.
4. 보고서 모드에서 초안을 작성하고 본문을 수정합니다. 기본 양식은 AI 없이 메모를 정리하며, 목표 글자 수는 AI 모드에 적용됩니다.
5. 공유하기로 기기의 공유 창을 엽니다. 카카오톡이 지원되는 기기에서는 공유 대상에 카카오톡을 선택합니다. 직접 카카오톡으로 자동 전송하지는 않습니다. HTML 저장에는 선택한 사진이 포함됩니다. PDF는 인쇄 메뉴의 PDF 저장을 이용합니다.

## GPT 연결

API 키는 브라우저에 입력하지 않습니다. 서버 프로세스에 `OPENAI_API_KEY`와 선택적으로 `OPENAI_MODEL`을 설정하고 `node server.mjs`를 실행합니다. 기본 모델은 `gpt-4.1-mini`이며 사용 가능한 모델명으로 변경할 수 있습니다. 설정에서 개인 GPT API 연결을 선택합니다. 동일 서버에서는 기본 주소 `/api/report`를 사용합니다.

GitHub Pages는 서버 코드를 실행할 수 없습니다. 따라서 Pages 배포본의 AI 작성에는 별도 HTTPS 백엔드가 필요합니다. 외부 백엔드는 접근 인증과 CORS를 배포 환경에 맞게 설정해야 합니다. 제공된 서버는 localhost 전용이며 외부 공개 전 인증·요청 제한·HTTPS 구성이 필요합니다. 키가 없어도 기본 양식, 편집, 보관, 공유를 사용할 수 있습니다.

AI 작성 시 제목·메모·재작성 요청과 선택한 사진을 서버 및 OpenAI에 보냅니다. 영상과 음성 원본은 AI에 보내지 않으며 텍스트 메모를 사용합니다. 사진 수를 0으로 하면 사진을 전송하지 않습니다. AI 결과는 저장 전에 사실관계를 확인하세요.

## 저장과 기기 제약

자료는 현재 기기·브라우저의 IndexedDB에 저장되며 GitHub에 업로드되지 않습니다. 자동 저장과 별개로 백업 버튼을 이용해 JSON 파일을 보관하세요. 브라우저 데이터 삭제 시 기기의 기록도 삭제됩니다. 백업 파일에는 사진·음성이 포함됩니다.

음성 녹음은 탭으로 시작/종료하거나 길게 눌러 사용합니다. 브라우저 음성 인식이 지원되면 텍스트 변환을 시도합니다. 갤럭시 내장 음성 인식을 웹에서 직접 제어하지는 않으며 키보드 마이크를 대안으로 사용할 수 있습니다. 브라우저 음성 인식은 브라우저 제공자의 네트워크 서비스가 사용될 수 있습니다. 카메라 초점은 기기가 지원할 때만 제어됩니다. 브라우저·기기에 따라 지원 범위가 다릅니다. 한 번의 녹음·녹화는 3분 또는 약 45MB로 제한합니다.

기획서의 최종 변경을 기준으로 촬영 기록을 모드 전환 아래에 배치했습니다. 화면 회전 시 가로 레이아웃을 사용합니다. 되돌리기는 최근 20회 변경을 현재 세션에서 보관합니다. 작업 리셋과 보고서 초기화는 확인 후 실행합니다. 첫 접속 후 앱 UI는 오프라인 캐시로 실행되며 AI는 온라인 연결이 필요합니다.
